# Live Better App

A friendly place to find movement that feels good. This static prototype brings workout building, coach-led guidance, wellness videos, and a simple weekly calendar into one home.

## Preview

Open `index.html` in a browser, or visit the [live app](https://lucasboccasini.github.io/Run-Better-App/). No build step is required.

## What's here

- Activity discovery with beginner and experienced options
- A workout builder for runs, lifts, football, lacrosse, cycling, mobility, and custom sessions
- Professional video resources for running, strength, nutrition, and sleep
- A weekly calendar that saves plans in the current browser on the current device
- Custom CSS illustrations instead of stock photos

## Project files

- `index.html` — home screen and activity sections
- `styles.css` — responsive blue-and-lime color palette and layouts
- `app.js` — activity filters, workout timer, and local calendar

## Project status

This is an early prototype. Activity suggestions and progress are examples. Calendar plans are saved locally in the browser and are not synced across devices.
